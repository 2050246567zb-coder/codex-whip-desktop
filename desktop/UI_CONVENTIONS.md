# 设置界面约定

按用户 2026-09-17 标注维护：

- 静态页面只保留标题、当前参数和必要操作，不堆叠说明段落、蓝色流程说明或未来功能预告。
- 校准开始后才显示当前动作引导及反馈；不删除识别失败或测试结果等必要状态。
- 时间参数采用“敲击间隔：0.6秒”样式。
- 新滑块复用 TickSlider：黑色进度、灰色轨道、白色圆心、下方刻度；默认连续拖动，不吸附刻度，无蓝色焦点外框，保留键盘调节。
- 禁用主按钮采用浅蓝底和清晰文字，不使用禁用位图网点效果；保留不可点击语义。
- 禁用按钮也保留与主按钮相同的圆角；滑块圆心按住放大、松开缩回，采用 160 毫秒可中断非线性缓动，不影响连续拖动位置。
- 日常 UI 微调不改变传感、识别和数据保存逻辑。
- 操作按钮以“开始校准”为比例基准：宽度按字体实际测量宽度加左右各 14 像素计算，不统一固定宽度；高度、7 像素圆角和启用/禁用几何保持一致，各自语义色保持不变。

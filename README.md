# Codex Whip · Codex 鞭子

## 自动安装

打开 [扫码安装页面](https://2050246567zb-coder.github.io/codex-whip-desktop/)，复制提示词发给要安装软件的电脑上的 Codex。Codex 应先阅读 [完整安装说明](https://2050246567zb-coder.github.io/codex-whip-desktop/INSTALL.md)，再按平台完成下载、校验、安装和启动，不要只下载或直接打开 DMG。

Mac 提供 [自动安装脚本](https://2050246567zb-coder.github.io/codex-whip-desktop/install-macos.sh)：自动选择最新的正式 Apple Silicon 包，校验后复制到固定应用目录，再启动并打开权限设置。辅助功能、蓝牙及安全确认由用户亲自完成，安装到桌面不是必要条件；桌面可以放快捷方式。

软件包在 [GitHub Releases](https://github.com/2050246567zb-coder/codex-whip-desktop/releases)。请选择本平台最新正式版，不要使用另一个平台的 Latest，也不要把 Source code 压缩包当成安装包。

# 0.7.0-c3 验证记录（2026-09-20）

## 已完成

- ESP32-C3 独立固件，原 XIAO 固件未修改。
- 引脚：MPU6050 SDA=0、SCL=1、AD0接地；ICS-43434 SCK=4、WS=5、SD=6、L/R接地。
- 两模块共地，使用3.3V；开发板暂用USB-C供电。
- Arduino ESP32 3.3.11 + NimBLE-Arduino 2.5.0 编译链接成功。
- Flash 679509 / 3145728字节；静态RAM 50824 / 327680字节。
  静态RAM数字不包括运行时BLE、I2S DMA等动态分配，不能视为实机内存验收。
- 74项测试通过：原有协议、语音、BLE客户端、灵敏度，以及新增C3命令/引脚约束、
  检测器/编码器一致性、20/97/244字节分片的桌面解析检查。
- 固件版本：0.7.0-c3，蓝牙名称保持CodexWhip；目标桌面版本2.2.32。
- 未改动桌面端运行逻辑或个人设置。

## 接线后仍需验证

尚未烧录，没有声称真实MPU6050读数、I2S录音或BLE吞吐已经通过。
需要验证：I2C识别/六轴方向、静止偏置、自动归中、轻重双敲、挥鞭/慢转区分、
录音增益和削波、长录音丢包、取消/重新录音、断线重连、Windows和macOS连接。
桌面语音识别准确率同时取决于麦克风安装和识别模型，不能由固件编译保证。
安装结构变化后请重新做方向、挥鞭、敲击校准。

## 文件与烧录注意

使用脚本scripts/compile-esp32c3.ps1可复现构建。
脚本使用临时P盘映射避开Windows中文SDK路径，并在结束后撤销自己创建的映射。
build/firmware-esp32c3输出应用、引导、分区和合并镜像。
不要将单个应用bin当作完整镜像烧到0地址；接线检查后优先通过Arduino上传整个工程。
不要把C3固件烧入原XIAO。首次连接请关闭原手柄，避免两个同名设备被误选。
